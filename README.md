# Элиас — игра в слова (PWA)
Статический сайт без бэкенда. Открыть `index.html` через любой https/localhost-сервер.
Файлы: index.html, app.js, style.css, words.js (слова), sw.js (офлайн), manifest.webmanifest, icons/.
Слова: Простые 508, Средние 555, Сложные 541, 18+ 373, Страсть 92, БДСМ 60, Намёки 115, Пошлые хиты 52 (строка припева + исполнитель и название).
Установка на iPhone: Safari → Поделиться → «На экран “Домой”».

Версия 10.0 (elias-v10): в «18+ Пошлые хиты» 52 карточки; двусоставные строки припева разрезаны на две карточки (например «Понюхай попку носиком» и «Прикинься киса пёсиком»). Версия 9.0: 4 строки припева Воровайки «Шмон». Версия 8.0: 4 строки припева Фактор-2 «Некому мне…» (фактор-2.com). Версия 7.0: строки припевов, кнопка «Предложить улучшение», голосовой ведущий (премиум-заглушка, без реальных платежей), фон-витрина с билбордом и грузовиком для рекламы. Supabase: общий «Топ» плейлистов и «Свои слова» с 👍/👎. Наказания 18+, режим «Для пары», модификатор «Алкоголь» — пейте ответственно. Плейлисты (в т.ч. Hush Hush и свой) — только ссылки, без встроенных треков.
