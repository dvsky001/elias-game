# Элиас — игра в слова (PWA)
Статический сайт без бэкенда. Открыть `index.html` через любой https/localhost-сервер.
Файлы: index.html, app.js, style.css, words.js (слова), sw.js (офлайн), manifest.webmanifest, icons/.
Слова: Простые 508, Средние 555, Сложные 541, 18+ 373, Страсть 92, БДСМ 60, Намёки 115, Пошлые хиты 80 (название + исполнитель).
Установка на iPhone: Safari → Поделиться → «На экран “Домой”».

Версия elias-v5: колода «18+ Пошлые хиты» (80), плейлисты (в т.ч. Hush Hush и свой), рейтинг-заглушка Supabase, наказания 18+ (прикосновения, «Найди точку», правда или действие, режим для пары, свои задания, модификатор «Алкоголь» — пейте ответственно).
